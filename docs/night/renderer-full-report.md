### 指示になく、自分で足したもの
「次にすることが一目で分かる」「壊す心配がない」のために足しました。不要なら外せます。

| 足したもの | 理由 |
|---|---|
| 最初の未チェックの手順に、差し色の枠と「次はこれ」の文字を付ける | 次の手順を色と文字の両方で示すため |
| 「終わった手順：3 / 15」の表示 | 長いページで進み具合を見失わないため |
| 接続先（`\\` で始まる値）を途中で折り返さず、薄い地色を敷く | 見ながら入力する値なので。タグを足すだけで、文字は変えない。コピーする文面も変わらない |

## 自分で決めたこと
`docs/design.md` は今回変更できないので、ここに書きます。問題なければ「決定事項」へ移してください。

| 決定 | 理由 |
|---|---|
| 手順ページでは、連絡先の「伝えること」を出さず、そのページの文面だけを出す | 「伝えること」は1社に1文で、別の症状の文のことがあるため。実際に、複合機の故障のページに「スキャンが届きません」と出ていた。連絡先のタブには全項目を出す |
| 判定が「業者へ連絡」のページは、見出しを「直らなかったら」から「連絡してください」に変える | まず連絡するのが手順で、「直らなかったら」では意味が合わないため |
| 手順の文以外（題名、判定の文など）に出てくる用語は、ページの最後の「このページのことば」にまとめる | 手順の前に用語が並ぶと、最初の手順が遠くなるため |
| 用語は長い語を優先して探す（「外付け USB」があれば「USB」を別に出さない） | 同じ語の説明が二重に出ないようにするため |
| 手順の下の用語は、縦に積まず横に並べる | 1つの手順に5語あるページで、次の手順が遠くなっていたため |
| 定期作業の手順にはチェック欄を付けず、開閉で読む | 毎週、毎月くり返す作業なので、チェックを残すと次回に邪魔になるため |
| 年の作業に「次は2027年3月」のような年を出さない | 基準日から計算すると、1年後に開いたときに誤った年になるため |
| 題名に月が書いてあれば月を重ねて出さず、なければ「毎年3月」と補う | 同じことを2回出さず、Writer が月を書かなかったときも分かるようにするため |
| 月が 13 以上なら止める（終了コード 1）。月のない年の作業は最後に並べる | スキーマは下限しか見ておらず、13月などでは並び順が壊れるため |
| 判定の「業者へ連絡」を赤ではなく墨色の四角にする | 不安な人に赤で警告しないため。形は、自分で直せる＝丸い帯と✓、確認してから＝角丸と！、業者へ連絡＝四角と電話の印 |
| 冒頭の飾りの印は入れない | オコジョの尾と姿の2案を撮影して見たが、角や猫のように見えた。迷ったら小さい方を選ぶ指示に従った |
| 用語集は入力の順のまま並べる | 漢字の読みが入力にないので、五十音順に正しく並べられないため |
| 根拠の文を「この手順は確認済みです。／もとにした情報：…」の2行にする | 「確認済みの標準手順で確認済みです」と重なるのを避けるため |
| フォントは `system-ui, sans-serif` だけを指定する | 実在のフォント名をリポジトリに書かないため |
