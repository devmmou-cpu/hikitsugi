# 夜間の作業：表示プログラムの初版（T1）

あなたは「ヒキツギ」の実装担当です。依頼者は寝ていて、質問には答えられません。判断に迷ったら、安全で小さい方を選び、報告書に書いてください。最初に `CLAUDE.md` と `docs/design.md` を読んでください。

## 作るもの
`plugin/renderer/render.mjs`：取扱説明書の中身（`plugin/schemas/manual.schema.json` の形式）から、スマホで読む HTML 1ファイルを作るプログラム。AI を使わず、同じ入力から毎回同じ出力を作ります。

入力の見本は `test/fixtures/manual-t1.json` です。範囲は **T1（共有フォルダが見えない）だけ**です。

## 合格条件
- `npm test` が全件成功すること。約束は `test/renderer.acceptance.test.mjs` の冒頭にあります
- `node scripts/check-secrets.mjs` が「問題なし」と出ること
- テストに書かれていない部分は、自由に設計してください

## 使う人
ITの経験がない総務担当者が、PC が不調なときにスマホで片手で開きます。不安な状態で読むので、次にすることが一目で分かり、壊す心配がないと感じられる画面にします。

## 画面の決まり
- **見た目の方向：** やさしく、落ち着いた、頼れる道具。派手な装飾はしない。既存のアプリに似せない
- **基準：** 幅 375px。指で押しやすく、片手で届く。下部のタブは固定し、内容に重ならないようにする
- **文字と色：** システムフォントのみ。色は CSS 変数で定義し、ライトとダークの両方で十分なコントラストにする。判定は色だけに頼らず、文字と形でも区別する
- **JavaScript なし：** 全文を上から順に読める。OneDrive やファイルアプリのプレビューを想定する
- **JavaScript あり：**
  - タブごとに1画面を表示する
  - チェックの状態を保存する（保存できない環境でも止まらない）
  - コピーボタンで文面をコピーし、押したことが分かるように表示を変える
- **印刷：** タブやボタンを隠し、黒い文字で全文を印刷できる
- **文言：** 画面の固定の文言は、IT の知識がなくても分かる日本語にする。記述の本文を書き換えない

## 守ること
- 変更してよいのは `plugin/renderer/` と `docs/night/renderer-t1-report.md` だけ。**`test/`、`eval/`、`plugin/schemas/`、`plugin/lib/`、`package.json` を変更しない**
- テストが厳しすぎると思っても、弱めない。通せなければ、理由を報告書に書いて止まる
- push しない。ブランチを切り替えない。API、ネットワーク、外部ライブラリを使わない
- T1 以外の機能（検索、他の症状、カレンダーなど）を足さない
- コメントは日本語
- 動く単位でコミットする。メッセージは日本語で、末尾に次の行を付ける

  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`

## 終わるとき
1. `node plugin/renderer/render.mjs test/fixtures/manual-t1.json night-logs/manual-t1.html` で朝の確認用の HTML を作る
2. `docs/night/renderer-t1-report.md` を書いてコミットする。内容は次のとおり
   - `npm test` の結果（件数）
   - 作ったものの要点と、自分で決めたこと
   - **確認できていないこと。** ブラウザーでの動作（タブ、チェックの保存、コピー）はテストでは確かめられないので、朝に見てほしい点として具体的に挙げる
   - 通せなかったテストがあれば、その理由
3. 全テストが通ったら、それ以上手を広げずに止まる
