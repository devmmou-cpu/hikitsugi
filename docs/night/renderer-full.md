# 夜間の作業：表示プログラムの完成版

あなたは「ヒキツギ」の表示プログラムの担当です。依頼者は寝ていて、質問には答えられません。判断に迷ったら、安全で小さい方を選び、報告書に書いてください。**時間をかけてかまいません。見た目を何度も確かめて、作品として仕上げてください。** 最初に `CLAUDE.md` と `docs/design.md` を読んでください。

## 作るもの
`plugin/renderer/` の表示プログラムを、完成版にします。取扱説明書の中身（`plugin/schemas/manual.schema.json`）から、スマホで読む HTML 1ファイルを作ります。AI を使わず、同じ入力から毎回同じ出力を作ります。

- 入力の見本：`test/fixtures/manual-full.json`
- 全タブ：困ったとき、連絡先、毎月やること、会社のIT（機器の一覧と用語集）
- 複数の手順ページ
- `docs/renderer-todo.md` の修正点をすべて直す。直したらチェックを付ける

## 使う人
- IT の経験がない総務担当者が、PC が不調なときに、不安な状態で、スマホを片手に開きます
- 次にすることが一目で分かり、壊す心配がないと感じられる画面にします

## 見た目の方向
- **やさしく、落ち着いた、頼れる道具。** 派手な装飾はしません。事務的すぎず、幼くもしません
- **雪のような白と墨色を基調に、控えめな暖色（オコジョの毛色：明るい茶色から赤みのある茶色）を差し色にします。** 差し色は、今いるタブ、番号、大事な操作など、意味のある場所にだけ使います
- 判定は色だけに頼らず、文字と形でも区別します
- ダークモードは、墨色を基調に同じ印象を保ちます。単に白黒を反転させません
- 既存のアプリのデザインに似せません。外部のフォント、画像、ライブラリは使いません。飾りが必要なら、インラインの SVG や CSS で作ります
- 余白、文字の大きさの段階、行の高さをそろえ、カードの角や線の太さを統一します

## 毎月やること
- 毎週、毎月、年に1回の順に並べ、年の作業は基準日（`as_of`）から近い順に並べます
- 手順があれば読めるようにします

## 手順の作業のしかた
1. HTML を作る：`node plugin/renderer/render.mjs test/fixtures/manual-full.json night-logs/manual-full.html`
2. 撮影して検査する：`node scripts/screenshots.mjs night-logs/manual-full.html night-logs/screenshots`
3. **`night-logs/screenshots/` の PNG を Read で開いて、自分の目で確かめます。** ライトとダークの全画面を見ます。崩れ、窮屈さ、読みにくさ、色の偏りを直します
4. 満足するまで 1〜3 を繰り返します。少なくとも3回は見直してください

## 合格条件
- `npm test` が全件成功すること。約束は `test/renderer-full.acceptance.test.mjs` と `test/renderer.acceptance.test.mjs` の冒頭にあります
- `node scripts/check-secrets.mjs` が「問題なし」と出ること
- テストに書かれていない部分は、自由に設計してください

## 守ること
- 変更してよいのは `plugin/renderer/`、`docs/renderer-todo.md`、`docs/night/renderer-full-report.md`、`night-logs/` だけ。**`test/`、`eval/`、`scripts/`、`plugin/` のほかの場所、`package.json`、`CLAUDE.md` を変更しない**
- テストが厳しすぎると思っても、弱めない。通せなければ、理由を報告書に書いて止まる
- push しない。ブランチを切り替えない。API、ネットワーク、外部ライブラリを使わない
- 検索、はじめにの画面、印刷用の緊急連絡カード、カレンダーのファイルは、今回は作らない
- 記述の本文を書き換えない。画面の固定の文言は、IT の知識がなくても分かる日本語にする
- コメントは日本語

## コミットのしかた
動く単位でコミットします。**コマンドは1つずつ実行し、`&&` でつなぎません。**

```
git add plugin/renderer
git commit -m "日本語のメッセージ"
```
メッセージの末尾には、次の行を付けます（`-m` を2つ続けて指定できます）。

`Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`

## 終わるとき
1. 最後の HTML とスクリーンショットを `night-logs/` に残す
2. `docs/night/renderer-full-report.md` を書いてコミットする。内容は次のとおり
   - `npm test` の結果（件数）と、撮影の検査の結果
   - 作ったものの要点と、自分で決めたこと（色の値も）
   - 見直しで直したこと
   - **確認できていないこと。** 実機の iPhone、OneDrive のプレビューでの見え方など、朝に見てほしい点を具体的に挙げる
   - 通せなかったテストがあれば、その理由
3. 全テストが通り、見た目にも満足したら、手を広げずに止まる
