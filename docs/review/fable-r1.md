## 指摘

区分の意味：【表示・文言】＝いまの事実だけで表示や文言を変えれば直る／【エージェント指示】＝Writer・Interviewer・Editor のプロンプトか検査の変更が要る／【限界】＝事実がないので「分かっていないこと」として書くしかない。

## 迷った点

- 高-2 の「ランプが消えているときだけ押す」は、一般の機器の常識であって聞き取りの事実ではない。手順部品として本人が承認するか、Interviewer で聞き直すかの判断が要る。承認なしで Writer に書かせるべきではない。
- 中-6 の INT-021〜027 は、渡された `transcript.json` が最新でない可能性がある。保存漏れでなければ、この指摘は材料の問題。
- 「つなぎ直すだけなので、データは消えません。」は言い切りだが、INT-016 の田中さんの言葉で技術的にも正しいので、直さなくてよいと判断した。
- 動画の T4 は、①と返す文だけで切れば現状でも見せられる。②まで映すなら中-7 と Windows 10 分岐の相手が映るので、先に直したい。
- 認証情報らしい値は、聞き取り・説明書とも値そのものは出ていない（管理画面のアドレスは聞き取りにあるが、認証情報ではない）。
