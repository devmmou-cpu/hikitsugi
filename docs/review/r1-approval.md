## 2. `windows11_only` の属性を付ける部品の案：付けない
文面は変えず、属性だけを足す案でした。属性が1つでも付くと、Windows 10 の帯は属性のある部品を使うページだけに出ます。付けないので、帯は PC の操作の部品が1つでもあるページに出ます。

| 部品 | 文面 | 理由 |
|---|---|---|
| LIB-003 | 画面の上の「…」を押して、「ネットワーク ドライブの割り当て」を選んでください。 | Windows 10 のエクスプローラーには「…」がない |
| LIB-004 | 「ドライブ」の欄で、…ドライブ文字を選んでください。 | 上の画面の続き |
| LIB-005 | 「フォルダー」の欄に、同じ行の接続先を入力してください。… | 上の画面の続き |
| LIB-006 | 「サインイン時に再接続する」にチェックを入れてください。 | 上の画面の続き |
| LIB-022 | 「完了」を押してください。 | 上の画面の続き |
| LIB-011 | Wi-Fi のマークの横にある「>」を押してください。 | Windows 10 の Wi-Fi の一覧には「>」がない |
| LIB-012 | 一覧で、…Wi-Fi の名前を選んで、「接続」を押してください。 | 上の画面の続き |
| LIB-027 | 「Wi-Fi」のボタンを押して、色のない状態にしてください。 | クイック設定のボタンの形 |

**属性を付けない案だった部品：** LIB-001、002、013、014（エクスプローラーの基本の操作）、LIB-010（右下の Wi-Fi のマーク）、LIB-018〜020（再起動）、LIB-024〜026（コピー）、LIB-028、029（OneDrive）。Windows 10 の実機では確かめていません。一般に知られた画面の違いからの案です。
