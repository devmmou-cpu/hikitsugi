# 佐藤さん役の通読（11/4）

実物の通し4回目の説明書（`night-logs/real-run-4/manual-after-update.html`）を、IT 未経験の総務担当として全ページ読んだ結果です。**模擬評価です。** 実在の後任が読んだものではありません。**ここでは直していません。**

**読んだ人：** 設計の経緯を知らない別のエージェントです。説明書の文字だけを渡し、設計書と聞き取りの記録は開かせていません。
**読み方の限界：** JavaScript なしの全文を文字で書き出して読みました。図、ボタンの形、押した先の動きは見えていません。

**数：** 81件（止まる 34、迷う 37、意味が分からない 10）。引用はプログラムで説明書の文と照合しました。全16ページのうち、「複合機が故障した・動かない」のページの中身には指摘がありません。

## 読むときの注意
- **#1 「当てはまる症状がないとき」：** PC 用はページではなく連絡先へのリンクです。書き出しでは中身が見えません。スマホ用の束には同じ名前のファイルがあり、社内の相談先の一覧が出ます（`99_当てはまる症状がないとき.html`）。
- **#80 「佐藤 確認」：** 通しの更新で、私が佐藤さんの名前を使ったことによるものです。実際の後任が自分で更新すれば起きません。ただし「確認した人」の意味が読む人に伝わらない点は残ります。
- **#81 日付の前後：** 調査データの日付が架空の 11/5 で、通しを 11/4 に行ったためです。録画を 11/5 以降にすれば起きません（`docs/review/consistency.md` の #25）。

## 全体で感じたこと（佐藤さん役の言葉）
書いてあるところまでは順に進めますが、「社内で相談してください」の相手が決まらず、工場の CAD 担当者には名前も連絡方法もないので、多くのページがそこで行き止まりです。

電源を抜く、ボタンを押す、ケーブルを抜くといった手順は、物の見分け方、待つ時間、直ったかの確かめ方がないと、怖くて実行できません。

社員がよく言いそうな「印刷できない」「メールが送れない」「PC が動かない」などに当たるページが見つからず、「当てはまる症状がないとき」の中身も読めないので、最初の一覧で迷います。
