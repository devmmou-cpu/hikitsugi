### iPhone の OneDrive で、スマホ向けの作りが動かなかった件
- **問題：** 本人の実機で確かめると、iPhone の OneDrive の表示では JavaScript もページ内リンク（#id）も動かず、上から順に読むことしかできませんでした。1ファイルでは、14症状を順に送るしかありません。
- **打った手：** PC 用の1ファイルは残し、スマホ向けに1ファイル1症状の束を足しました。OneDrive のフォルダの一覧が目次になるので、ファイル名に番号、判定、症状を入れました。script もリンクも置かず、その症状で使う表と連絡先を同梱します。
- **数字：** ファイル数 16／14／13、1ファイルの最大 10.6／10.4／9.5KB（上限 200KB）。JavaScript なしの撮影で、3社の全ファイルが検査に合格しました。**束を iPhone で開く確認は、まだです。**

## 既知の差
正解データは変えず、差として記録します。

- **キノドテン建設の「ネットが全部つながらない」：** 正解は「連絡（クロテン通信）」です。出力は実行によって変わり、「ルーターを再起動して、直らなければクロテン通信に電話」という「自分で直せる」（`20261102T224611`）や「確認してから」（`20261102T234454`）のページになることがあります。前の実行では「業者へ連絡」でした。再起動の手順は聞き取りに根拠があり、Verifier は合格しています。後任が最終的にクロテン通信へ連絡する点は同じですが、判定は一致しません。

## README の「限界」に書く候補
- **入力量の上限：** 調査データの ID は PC 50台、1台あたりソフト500件まで足りますが、その量（約420万字）は Writer に一度に渡せないと考えられます。今は直しません。18台で1台52件なら約15万字で、収まる見込みです。
- **模擬の田中さんの限界：** 「分からない」「あとで」がほとんど出ません。上の「質問数が 20問から減った件」のとおりです。
- **載せ漏れ検査の限界：** 語句の照合なので、言い換えられた事実は見逃すことも、誤って止めることもあります。
- **実機で確かめていないこと：** Wi-Fi で接続中の名前、ネットワーク ドライブの読み取り、複数台のまとめ。
